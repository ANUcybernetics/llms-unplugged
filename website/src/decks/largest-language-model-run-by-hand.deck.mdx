## the algorithm

![bg right:40%](./assets/bg-algorithm-generation.avif)

1. I **call out** the last token we wrote (and its colour)
2. **hands up** if it's the _boxed_ token on your page
3. I **pick a hand at random** --- you read out the token beside it
4. I **write it down**, and we go again

```notes
describe the algorithm (reading from the screen is fine)

then call for a volunteer and get the first pair: boxed token first, both go on the board
```

## what role did you play?

![bg right:40%](./assets/bg-core-insight-portrait.avif)

the pairs on your page → the **parameters** of the model

the hands in the air → the **probability distribution** over next tokens

my random pick → **sampling**

the sentence I wrote → **generation**

```notes
read from the slide

about 6k token pairs (parameters): not quite the trillion or so of a frontier model, but the same loop
```

## three books

{/* prettier-ignore */}
<p class="corpus-a fragment">“He was an old man who fished alone in a skiff in the Gulf Stream.”<br /><span class="corpus-attribution">— Ernest Hemingway, <em>The Old Man and the Sea</em> (1952)</span></p>
<p class="corpus-c fragment">“TRUE! nervous, very, very dreadfully nervous I had been and am.”<br /><span class="corpus-attribution">— Edgar Allan Poe, <em>The Tell-Tale Heart</em> (1843)</span></p>
<p class="corpus-b fragment">“The sun did not shine. It was too wet to play.”<br /><span class="corpus-attribution">— Dr. Seuss, <em>The Cat in the Hat</em> (1957)</span></p>

```notes
each token pair came from one of these three books (read them out one by one)

the sheets never said which book a pair came from, and the model couldn't tell either

it worked because the books share contexts: "the", "said", "I", "old man" (Hemingway and Poe both have one)
```

## everything else this week modifies this loop

![bg right:40%](./assets/bg-algorithm-generation.avif)

**test-time scaling** → draw more samples before you commit

**RL with verifiable rewards** → change what the distribution is trained towards

**speculative decoding** → let a small model draw the sample, a big one check it

**an LLM judge** → point the loop at another loop's output

```notes
a language model is a distribution over the next token, and generation is sampling from it and feeding the sample back in. You just did that.

every concept on today's programme is a modification of that loop. Now you have somewhere to hang them.
```
