# Generation

![bg](./assets/bg-ledger-title.avif)

```notes
Groups of 4-5, if the room isn't in them already; they stay in those groups all session. Hand out the sheets now, one per person. Keep the counters back until the activity slide: nobody has been told what the colours mean yet, and a cup on the table ends up on the floor.
```

## This is a language model

<LedgerSheet entries={SHEET_FIVE} palette={PALETTE} />

```notes
Take your time here. This is one sheet of the model. Left column: words from the book. Along each row: the words that followed, with a tally mark for each time that pair appeared in the book. Let them look at it before you point to a row.
```

---

## One row at a time

<LedgerSheet entries={SHEET_FIVE} palette={PALETTE} focus="the" />

```notes
Read the row aloud as a sentence: after the word "the", this book said "magpie" six times, and "fence", "postie" and "dog" four times each. The magpie groups can find this exact row; every other group finds the row for a word they like in their own book and reads it the same way. Two or three groups read theirs out.

The colours go here too: every word sits in a coloured box, and the counters come in those four colours, so a red counter means the word in the red box. Red means "fence" on this row and "the" on the row for "swoops": the colour marks the box position rather than a fixed word, so one set of counters works for every row and every book.
```

## Your group holds the whole model

<LedgerSheets ranges={SHEET_RANGES} palette={PALETTE} />

```notes
Every sheet holds an alphabetical range of words shown in the header. To find a word, check the headers rather than scanning every row. These are the magpie headers; every book splits differently, so each group practises on its own sheets. Run two lookups ("who has it?", "who has fence?").
```
