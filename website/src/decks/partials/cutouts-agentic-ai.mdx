## What makes a model an "agent"?

![bg right:40%](./assets/bg-insight-tool-use.avif)

an agent is a model that can **call tools**: pause generation, get information
from "outside" the model, and continue

the loop: generate → trigger word → call tool → write the result → keep going

```notes
The beat: the model pauses, gets information from outside itself, then continues. The loop is the thing.
```

## Tools: GOOGLE, FRIEND

![bg right:40%](./assets/bg-tool-use-triggers.avif)

| Trigger                         | Tool                                        | Returns                   |
| ------------------------------- | ------------------------------------------- | ------------------------- |
| <Token next tool>GOOGLE</Token> | a phone search                              | one word from the top hit |
| <Token next tool>FRIEND</Token> | text a friend `What comes next? "[sentence so far]..."` | first reply wins |

```notes
Two tools: GOOGLE = search on a phone, read the first word of the top hit; FRIEND = everyone texts a friend `What comes next? "[sentence so far]..."`, first reply wins. The prompt asks for a continuation instead of leaving friends to decipher a mysterious fragment. Swap in your own if you like.
```

## Worked example

each tool-use cutout pairs a trigger with a closing period---the tool's
response slots in between:

<CutoutRow>
  <Cutout prev="a" next="GOOGLE" tool="next" trailing="." />
  <Cutout prev="the" next="FRIEND" tool="next" trailing="." />
</CutoutRow>

generating from <Token next>a</Token>, you might pick <Cutout prev="a" next="GOOGLE" tool="next" trailing="." />---write <Token next tool>GOOGLE</Token>

hand off to the tool operator---they search on their phone and read out the
first word of the top hit ("recipe")---write <Token next>recipe</Token>, then
the trailing <Token next>.</Token> from the cutout, and continue

```notes
Walk one pick slowly: land on GOOGLE, hand to the operator, they read back one word, write it plus the cutout's trailing full stop, then continue.
```

## The _language_ of language models

![bg right:60%](./assets/bg-vocabulary.avif)

agent

tool call

```notes
Everyday sense first, then ours: an agent is a travel agent or a secret agent, someone who acts for you --- here it's a model that can act, not just talk. A tool call sounds like reaching for a hammer --- here the model asks for something outside itself and waits for the answer. If anyone asks what runs the loop: *you* did. The harness is the scaffolding around the model that pauses it, hands off to the tool, and writes the result back --- here, that was the students and the tool operator between them.
```
