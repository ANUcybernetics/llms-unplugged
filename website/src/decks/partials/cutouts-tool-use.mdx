# Agentic tool use

![bg](./assets/bg-tool-use-banner.avif)

---

## What makes a model an "agent"?

![bg right:40%](./assets/bg-insight-tool-use.avif)

an agent is a model that can **call tools**: pause generation, get information
from "outside" the model, and continue

the loop: generate → trigger word → call tool → write the result → keep going

---

## Your goal

![bg right:40%](./assets/bg-tool-use-handoff.avif)

add **tool-use cutouts** to your spread and designate a tool operator

when generation hits a trigger word, pause---the operator runs the tool and the
result becomes the next word(s)

---

## Tools: GOOGLE, FRIEND

![bg right:40%](./assets/bg-tool-use-triggers.avif)

| Trigger                         | Tool                    | Returns                      |
| ------------------------------- | ----------------------- | ---------------------------- |
| <Token next tool>GOOGLE</Token> | a phone search          | one word from the top hit    |
| <Token next tool>FRIEND</Token> | everyone texts a friend | first single-word reply wins |

---

## Worked example

each tool-use cutout pairs a trigger with a closing period---the tool's
response slots in between:

<CutoutRow>
  <Cutout prev="a" next="GOOGLE" tool="next" trailing="." />
  <Cutout prev="the" next="FRIEND" tool="next" trailing="." />
</CutoutRow>

generating from <Token next>a</Token>, you might pick <Cutout prev="a" next="GOOGLE" tool="next" trailing="." />---write <Token next tool>GOOGLE</Token>

hand off to the tool operator---they search on their phone and read out the
first word of the top hit ("recipe")---write <Token next>recipe</Token>, then
the trailing <Token next>.</Token> from the cutout, and continue

---

## You will need

![bg right:40%](./assets/bg-tool-use-operator.avif)

**in pairs**

your trained cutouts spread (already on the table)

a stack of tool-use cutouts to add in

**tool operators** (one per tool) and phones for GOOGLE/FRIEND

pen and paper to write down the generated text

---

## Activity (15 min)

![bg right:40%](./assets/bg-activity-tool-use.avif)

add tool-use cutouts to your spread

generate---when you hit a trigger word, hand off to the tool operator

write the operator's answer down as the next word(s), and continue generating
