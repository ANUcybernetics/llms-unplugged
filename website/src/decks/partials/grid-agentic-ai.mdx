## What makes a model an "agent"?

![bg right:40%](./assets/bg-insight-tool-use.avif)

an agent is a model that can **call tools**: pause generation, get information
from "outside" the model, and continue

the loop: generate → trigger token → call tool → write the result → keep going

{/* notes:
The beat: the model pauses, gets information from outside itself, then continues. The loop is the thing.
*/}

---

## The recipe

![bg right:40%](./assets/bg-tool-use-triggers.avif)

{/* notes:
<ol>
<li><strong>generate</strong> from the booklet as before, rolling for each next word</li>
<li>when you land on a <strong>punctuation token</strong> (like <code>.</code> or <code>,</code>), pause --- that's a tool call</li>
<li><strong>text the word you just wrote</strong> to 3 friends</li>
<li><strong>write down</strong> the first word of the first reply, then the punctuation token you rolled</li>
<li><strong>continue</strong> generating from the punctuation token</li>
</ol>
*/}

generate from the booklet as before, but every punctuation token triggers a
**tool call**: text the previous word to 3 friends, and the first word of the
first reply goes into your text---followed by the punctuation you rolled

---

## Worked example

![bg right:40%](./assets/bg-example.avif)

your text so far is "the cat sat", and the next dice roll gives you `.` as the next
token---pause, that's a tool call

text "sat" (the last token before the `.`) to 3 friends;
the first reply back might be "down by the river"

write `down`, then the `.` you rolled anyway, and continue generating from `.`

{/* notes:
Walk it slowly: the punctuation is the trigger, the previous word is the tool input, the first word of the first reply is the tool result. The punctuation still gets written --- the tool result slots in just before it. If asked why we don't continue from the friend's word: it probably isn't in the booklet's vocabulary, so resuming from the punctuation token is the cleanest way to keep generating.
*/}

## The _language_ of language models

![bg right:60%](./assets/bg-vocabulary.avif)

- agent
- tool call
- agentic loop
- agentic AI

{/* notes:
Gloss each: agent = a model that can act, not just talk; tool call = it asks for something outside itself; agentic loop = generate, call, read the result, repeat; agentic AI = the umbrella buzzword for all of this --- and now they know what's underneath it. If anyone asks what runs the loop: *you* did. The harness is the scaffolding around the model that pauses it, makes the call, and splices the result back --- here, that was the students themselves.
*/}
