## Some words we'll use

![bg right:40%](./assets/bg-vocabulary.avif)

<p class="fragment"><strong>artificial intelligence (AI)</strong> — technology that mimics some human abilities, like writing stories or answering questions</p>

<p class="fragment"><strong>language model</strong> — a system that predicts what word comes next, using patterns it learned from text</p>

<p class="fragment"><strong>training</strong> — building a model by finding patterns in text</p>

<p class="fragment"><strong>training data</strong> — the text used to train a language model</p>
