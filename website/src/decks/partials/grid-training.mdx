## The recipe

![bg right:40%](./assets/bg-algorithm-training.avif)

```notes
1. **tidy up** your text: lowercase everything, treat words and single
   punctuation marks (`. , ! ? ; :`) as separate tokens
2. **set up** your grid: first token goes in both the row &amp; column headers
3. **fill in** the grid: for each consecutive pair of tokens, add a tally mark
   in that cell (add new rows/columns as needed)
```

walk through your text and tally up which tokens follow which in a grid

## A few more tips

![bg right:40%](./assets/bg-training-tips.avif)

you don't have to start at the beginning; any page will do

the last token in one sentence is followed by the first token in the next (even
over the page)

you can ignore quotation/speech marks (`"`)

work in pairs and divide the labour however you like, making sure you keep up
with the tally marks

```notes
Groups don't need to start at the beginning of the text: a model trained on page 5 is just as good as one trained on page 1, so let them open anywhere (and groups sharing a text can each take a different page). Treat the text as one continuous stream across sentences and page breaks: a full stop is followed by whatever word comes next. Skip quotation marks instead of giving them a row and column. Pairs work well if one person reads aloud while the other tallies, swapping partway through; the tally marks are the model, so a pair that races through the reading and skimps on tallying has nothing to generate from.
```

## Your turn

![bg right:40%](./assets/bg-design-your-model.avif)

tidy up your text, then for each pair of tokens:

1. **find the row** for the first token (if it's new, add a row _and_ a column)
2. **find the column** for the second token (adding a row and column if it's new)
3. **add a tally mark** in the cell where they meet
4. **move along by one**: the second token starts the next pair

```notes
Leave this slide up while they work. Hand out the grids; each group tallies its own text. 10 min, circulate. Watch for groups adding duplicate rows or columns: each token gets a new row and column only the first time it appears.
```

## The _language_ of language models

![bg right:60%](./assets/bg-markov.avif)

- model
- token
- weights

```notes
Everyday sense first, then ours: a model is a fashion model or a model aeroplane; here it's the grid that captures the patterns. A token is a bus token or a token gesture; here it's one word or punctuation mark. Weights are what you lift at the gym, or what you weigh up before deciding; here they're the tally marks that make some next words likelier than others. Point at a cell: when you hear a model has billions of weights, that's what's being counted.
```
