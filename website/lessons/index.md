# Lessons

Browse all lessons organised by topic. Each lesson includes step-by-step instructions for students and instructor notes connecting the activity to modern AI systems.

## Getting started

New to LLMs Unplugged? Start with the **Fundamentals** topic:

1. [Weighted Randomness](/lessons/weighted-randomness) — Learn the core sampling technique
2. [Basic Training](/lessons/basic-training) — Build your own bigram language model
3. [Basic Generation](/lessons/basic-generation) — Generate text from your model

## All topics

### Fundamentals

Core concepts for building and using language models.

- [Weighted Randomness](/lessons/weighted-randomness) — Make random choices where some options are more likely
- [Basic Training](/lessons/basic-training) — Build a bigram language model by counting patterns
- [Basic Generation](/lessons/basic-generation) — Generate text through weighted random sampling

### Scaling Up

Move beyond hand-built models to explore pre-trained models and longer context windows.

- [Trigram Model](/lessons/trigram-model) — Use two previous words for better predictions
- [Context Columns](/lessons/context-columns) — Understand how context affects predictions
- [Pretrained Generation](/lessons/pretrained-generation) — Use a pre-computed model booklet

### How Models Understand

Explore how models use context and represent word meaning.

- [Word Embeddings](/lessons/word-embeddings) — Discover how words become numbers

### Adaptation and Data

Discover how models are customised for specific tasks.

- [LoRA](/lessons/lora) — Fine-tune models efficiently
- [Synthetic Data](/lessons/synthetic-data) — Explore the risks of training on AI-generated data

### Controlling Output

Learn how sampling strategies shape generated text.

- [Sampling](/lessons/sampling) — Control randomness with temperature and truncation
