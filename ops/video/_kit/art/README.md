# Line-art sources

Public-domain (CC0) silhouettes the kit draws as outlines only (`K.outline`);
`../../build-data.py` flattens them into `generated/data.js`.

- `dog.svg`: "Standing dog silhouette", openclipart 169096
  (https://openclipart.org/detail/169096/standing-dog-silhouette), CC0.
- `magpie.svg`: pied currawong (_Strepera graculina_), PhyloPic image
  ac6920cc-61a3-4d33-86b6-e8da07011f87
  (https://www.phylopic.org/images/ac6920cc-61a3-4d33-86b6-e8da07011f87), CC0.
  The Australian magpie's closest relative with a CC0 silhouette; no CC0
  Australian magpie exists.

Icons (the phone, speech bubble, mug and person) come from iconoir via the
website's `@iconify-json/iconoir` dependency (MIT).
